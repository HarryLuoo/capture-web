Capture Shortcuts

Open this page in Safari on the iPhone. Tap one, then "Add Shortcut", and paste the inbox token when asked. Start with Note: it is the simplest test.

Capture Notetype or dictate a line Capture Photocamera, then optional words Capture Voicerecords audio; tap to stop Capture Screenscreenshots what is on screen Capture Imageshare sheet: screenshots, photos Capture Linkshare sheet: links, posts, text

Then

  1. In Shortcuts, put the first four in a folder named Capture.
  2. Settings → Action Button → Shortcut → choose the folder "Capture" (it shows the four as a menu), or one Shortcut.
  3. Settings → Accessibility → Touch → Back Tap → Double Tap → Capture Screen.
  4. Lock Screen: long-press → Customize → a bottom control → Shortcut → Capture Photo or Capture Voice.
